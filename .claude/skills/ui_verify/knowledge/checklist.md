## §34.4 床のレビュー（§8 の表を実サイズの画面で数える）

- [ ] Display Typography の見出しが1つ以上ある
- [ ] Primary Accent を面で出している場所が1つ以上ある
- [ ] 崩しが2か所以上、別々の部品にある
- [ ] 物質を持つ面が2つ以上あり、うち1つはステッカー以外である
- [ ] Dense な領域と Loose な領域が両方ある
- [ ] Hover / Selected / Pressed が3つとも作られている

**部品単体では数えない。** 実際に画面に組んだ状態で数える（§8.2）。単体では入っていても、画面に置くと他に埋もれて見えなくなることがある。

## §34.5 「暗いIDE化」判定（1つでも当てはまったら作り直す）

- [ ] バッジとステッカーを全部外すと、汎用のダークテーマIDEと区別が付かない
- [ ] 白黒にすると、画面の構成に特徴が何も残らない
- [ ] 楽しさを担っている部品が2つ以下しかない
- [ ] サイドバーに同じ強さの塗りアイコンが7個以上縦に並んでいる
- [ ] ツールバーが同じ形の器の等間隔の列になっている
- [ ] 状態バッジが専用の列になっている
- [ ] ステッカーが1つも出ていない
- [ ] アイコンから種別色が抜けて、ほぼ単色になっている

**後ろの2つ（ステッカー皆無・種別色抜け）は、抑制のしすぎで落ちた形である（§8.3）。** 「やりすぎ」だけでなく「やらなさすぎ」でもこの判定に引っかかる。

## §8 必達要素と最低数（Floor）の表

主要画面1枚には、以下を最低数以上入れる。

| 必達要素 | 最低数 | 置く場所 | 満たしていない例 |
|---|---|---|---|
| Display Typography の見出し | 1 | 画面の主題を示す位置 | 既定のUIフォントを太字にしただけ |
| 面で出す Primary Accent | 1 | 選択・現在地・主要操作のいずれか | アクセント色が細い線と小バッジにしか出ていない |
| Controlled Asymmetry の崩し | 2 | 別々の部品に。少なくとも1つは目に入る位置 | 画面の隅を1か所切っただけ |
| 物質感を持つ面 | 2 | 物質感の節の適用先の表から選ぶ。うち1つはステッカー以外 | ステッカーだけが物質を持っている |
| Dense な領域 / Loose な領域 | 各1 | 一覧はDense、見出し帯と操作群はLoose | 全領域が同じ行間・同じ密度 |
| 目に見える反応 | 3 | Hover / Selected / Pressed | Selected しか作っていない |

「最低1つ」は下限であって上限ではない（§8.1）。優先順位（分かりやすい→…→楽しい→派手）は省略の許可ではなく、床は順位と無関係に必達（§8.5）。
