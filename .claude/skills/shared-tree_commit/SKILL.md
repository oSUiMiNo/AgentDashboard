# shared-tree_commit

このツリーは複数の Claude セッションが同時に触る。`git add -A`・`git commit -a`・`git stash` は他人の未コミット分を巻き込む（実際に複数回起きている）。このスキルは、自分が触ったファイルをセッションの記録（`.jsonl`）から機械的に引き、他人の札（`claim`）と照らし合わせたうえで、作業単位ごとにハンク単位でコミットする。

[mainflow.md](mainflow.md) の手順に従い、タスクを実行せよ。実行中に問題が起きた場合は `mainflow.md` を更新し、`memory_improvement/` に記録せよ。

## 自己改善ルール

- 起動時、このスキル宛ての `PROPOSAL.md` が存在すれば未完了行（`[ ]`）を読む。手順を1つ直せば済むものはその場で `mainflow.md` へ反映して `[x]` にし、変更ログへ1行足す。2つ以上の段に触るものは触らず、`proposal_maintain` の判断に任せる
- 実行中にツール（`touched-files`・`claim`）の挙動変化を発見したら `mainflow.md` を更新する
- ユーザーからの指摘・修正依頼があった場合は必ず改善対象として扱う
- 改善を行った場合は `memory_improvement/` 配下に状況・原因・改善内容を記録する
- 既存ドキュメントに該当する記載がある場合は新規作成ではなく既存を更新する
- 仕様の記述不足・曖昧さに起因する問題は初回でも改善対象。純粋なオペミス（仕様は明確なのに手順を読み飛ばした等）のみ対象外
- 終了時、この回で無駄だった読み込み・往復が1つでもあれば `memory_improvement/` へ1行残す。問題が起きなかった回でも書く

## ディレクトリ構成

```
shared-tree_commit/
├── SKILL.md              # エントリポイント + 自己改善ルール（本ファイル）
├── mainflow.md            # ワークフロー手順（段ごとに誰がやるかを付す）
├── memory_improvement/    # 改善記録
│   └── README.md
└── bin/
    └── touched-files      # セッション記録から触ったファイル一覧を引く道具
```
