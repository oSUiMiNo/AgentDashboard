## 案詳細（改善案提出スキルが必ず記載）

### 1
提案：`state-doc-update` のアンカー置換を、現況 doc に「実測欄」を1ブロック設けて丸ごと差し替える方式へ変える。
担当イシュー：PJTスコープに本PJT専用の開発効率化スキルを作成
背景：初回の本番（0.1.147）で、走行版・予約の値が doc 内に2箇所ずつあり「手で直す」で終了4になった。人が一度一意化すれば以後は当たるが、doc が手書きである限り同じことが再発しうる。
特記事項：doc は `render.py` の出力に見えるが元 JSON が無い。元を JSON に戻して `render.py` で描き直す道と、HTML に実測欄だけ持つ道のどちらかを決める必要がある。

### 2
提案：bin/state-doc-update が走行版・ディスクの版・PID・起動時刻・予約の有無の欄を毎回『アンカーが1箇所に定まらない』として何も書かず、いま動いているもの.html が版上げのたびに古いまま残る。アンカーを一意にするか、JSON から描き直す形に変える
担当イシュー：ファイルビュアにエディタ機能を追加
背景：2026-09-28、0.1.148 と 0.1.149 の2回とも同じ6欄が『手で直す』で止まり、文書は1度も更新されなかった
特記事項：無し
