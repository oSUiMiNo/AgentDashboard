# `--now` で配ると前回の実行時刻が残らない

---
<br/>
<br/>

## 何が起きたか
`--now` で 0.1.148 を配ったあと、段6の `periodic arm` が次回を「いま＋1分」（19:50）に予約した。
そのまま待つと、直後に `--tick` が起動し、次の直しのコミットを拾って別の版上げを始めるところだった。

---
<br/>
<br/>

## なぜ
実行時刻（`last_run`）を書くのは `periodic tick` だけで、`--now` の入口は `tick` を通らない。
`arm` は `last_run + 周期` と `いま＋1分` の遅いほうを選ぶので、`last_run` が古いままだと「いま＋1分」になる。

---
<br/>
<br/>

## どこを直したか
`mainflow.md` §6-7 に、`--now` のときは `arm` の前に `periodic tick version_release` を1回呼んで実行時刻を進める、と足した。
