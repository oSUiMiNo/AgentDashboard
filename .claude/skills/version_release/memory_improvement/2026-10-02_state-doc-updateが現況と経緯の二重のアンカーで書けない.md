# state-doc-update が、同じ欄が現況と経緯の2か所にあって何も書かない

---
<br/>
<br/>

## 何が起きたか
0.1.160 を配った段5で、`bin/state-doc-update` が「手で直す：走行版・ディスクの版（2件）／PID・起動時刻（2件）／予約の有無（2件）」と出し、「差分が確定しない欄があるため何も書かない」で終わった。`いま動いているもの.html` は 09-17（0.1.147）から一度も自動で直っておらず、10-02 の時点で13版ぶん古かった。

---
<br/>
<br/>

## なぜ
探す目印（アンカー）が、「いまの状態」の文と「過去の経緯」の文の両方に出てくる。1か所に決められない欄は書かない作りなので、ドキュメントに経緯が積もるほど書けなくなる。手で直すときに「以下は 09-17 時点の記述」と前置きして古い文を残すと、同じ形の文が増えて次も書けない。
