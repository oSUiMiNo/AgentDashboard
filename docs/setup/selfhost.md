# セルフホストで使う

サーバを1台立てて、そこへ**複数の PC** を繋ぐ使い方。外出先のスマホから、家の PC で動いているセッションを見て操作できる。

1台で完結させたいだけなら [ローカルで使う](local.md) のほうが早い（サーバは要らない）。

```
             ブラウザ（スマホ・別の PC）
                    │
              ダッシュボードサーバ ── PostgreSQL
                    │              └ Valkey（2台以上に増やすときだけ）
         ┌──────────┴──────────┐
    仕事用ノート            自宅デスクトップ   ← agentdashboard-agent
```

**セッションの実体は PC の中**にある。サーバを再起動しても、走っている Claude Code は死なない。

<br/>

## 要るもの
| もの | どこに |
|---|---|
| Docker（compose が使えるもの） | サーバにする機械 |
| 本物の `claude` と認証 | 繋ぐ PC のほう（サーバには要らない） |

---
<br/>
<br/>

## 1. サーバを立てる（〜2分）
`docker/compose.yml` を取ってきて、そのディレクトリで：

```
docker compose up -d
```

3つ立つ。

| サービス | 役 |
|---|---|
| `dashboard` | 本体。`8787` で待ち受ける |
| `postgres` | 記録の置き場所（一覧・履歴・アカウント） |
| `valkey` | サーバを2台以上並べるときの連絡係。1台なら**無くてよい** |

**データベースの作り込みは要らない。** 表は起動時に自動で当たる。

---
<br/>
<br/>

## 2. 管理者を作る（〜1分）
ブラウザで **`http://<サーバ>:8787/setup`** を開き、名前とパスワードを決める。

この画面は**一度きり**しか開かない。作ったあとは通常のログイン画面になる。

---
<br/>
<br/>

## 3. PC を繋ぐ（〜1分半）
[ペアリング](pairing.md) へ。トークンを発行して、PC 側でエージェントを起動する。

ダッシュボードに PC が現れたら完了。

---
<br/>
<br/>

## インターネットから使う
アプリは HTTP しか話さない。TLS は前段のリバースプロキシで終端する。設定例と注意点は [リバースプロキシ](reverse-proxy.md) にある。

ドメインを持っていないなら、Tailscale や Cloudflare Tunnel で繋ぐ手もある。どちらの場合も、アプリ側でやることは同じ1つ：

```
AGENTDASHBOARD_COOKIE_SECURE=true
```

HTTPS で開くのにこれを付けないと、**入館証が平文でも送られる**。

---
<br/>
<br/>

## サーバを2台以上に増やす
`dashboard` を複数立てて、前段で振り分ける。揃えるのは2つだけ。

| 環境変数 | 揃える理由 |
|---|---|
| `DATABASE_URL` | 一覧も履歴もここが正。台ごとに違うと別々のダッシュボードになる |
| `VALKEY_URL` | 揮発の知らせ（画面・指示・在席）を配る。**1台なら要らない** |

それ以外は台ごとに違ってよい。

ブラウザが繋いだ台に、その PC が繋がっていなくても操作できる。片方の台を落としても、**セッションは死なない**（実体は PC の中にある）。

---
<br/>
<br/>

## 設定
環境変数はすべて `AGENTDASHBOARD_<大文字のキー>`。キーの一覧は `server/config.toml.example` が兼ねている。

慣行として `DATABASE_URL` と `VALKEY_URL` は接頭辞なしでも受ける（接頭辞つきが勝つ）。

## うまくいかないとき
| 症状 | 見るところ |
|---|---|
| `/setup` が「もう作れません」と言う | 管理者は作成済み。ログイン画面（`/`）から入る |
| ログインしてもすぐ弾かれる | HTTPS で開いていないのに `AGENTDASHBOARD_COOKIE_SECURE=true` にしていないか。Secure の入館証は HTTPS でしか送られない |
| PC が一覧に出ない | [ペアリング](pairing.md) の「うまくいかないとき」へ |
| 一部のブラウザにだけ更新が来ない | 台を増やしたのに `VALKEY_URL` を渡していないか。画面上部に連絡係の縮退が出る |
